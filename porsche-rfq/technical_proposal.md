## 一、公司概况与资质

### 1.1 公司简介

飞力达在全国设有40余个分支机构和物流中心，服务网络覆盖华东、华南、华北、华中及西南地区，年营业额逾50亿元人民币。公司长期服务于保时捷、宝马、奔驰、大众、奥迪等国际知名汽车品牌，是汽车行业头部主机厂及零部件供应商的核心物流合作伙伴。

### 2.4 SAP/EWM 系统对接方案

#### 2.4.1 系统对接架构

飞力达将作为PCN SAP EWM系统的终端用户进行操作，系统所有权归PCN，飞力达负责日常运营中的所有系统操作任务。

```
PCN SAP S/4HANA (总部ERP)
        │
        │ RFC/IDoc / EWM Inbound
        ▼
SAP EWM (PCN Managed) ─── 临港PDC仓库执行系统
        │                        │
        │ EWM User               │
        │ (飞力达操作员)         │
        ▼                        ▼
飞力达操作终端 ◄──── 手持扫描器/标签打印机/看板系统
```

#### 2.4.2 关键操作流程与系统集成

**入库流程（SAP EWM集成）：**
1. PCN在SAP中创建采购订单（PO），入库通知（ASN）自动推送至EWM
2. 货物到达后，收货员使用手持扫描器扫描ASN条码，系统自动带出待收货物信息
3. 质检（如有）通过EWM质检任务（Quality Inspection）执行，结果回传SAP
4. 上架时，扫描库位条码+零件条码，系统自动完成库存账务更新
5. 全程操作时间戳记录，满足KPI可追溯要求

**出库流程（SAP EWM集成）：**
1. PCN在SAP创建VOR订单或库存订单，通过IDoc推送至EWM
2. EWM自动触发波次计划（Waves），生成拣货任务
3. 拣货员扫描拣货，系统记录拣货路径和时间
4. 复核环节扫描出库零件与订单匹配，系统自动过账（Goods Issue）
5. 运输单据自动生成并回传PCN系统

**VOR紧急订单处理：**
- VOR订单优先级标记为"Urgent"，EWM自动优先处理
- 系统实时监控VOR订单处理时间，触发SLA预警
- VOR出库后自动触发PCN通知（邮件/SMS）

### 4.1 入库流程

                                              │
                                              ▼
                      ┌──────────────────┐   异常处理

                    ▼                      ▼
              【无需质检】            【需要质检】

                    │                      │
                    └──────────┬───────────┘

                         库位分配与上架
                               │
                               ▼
                         上架确认与系统过账
                               │
                               ▼

#### 4.1.2 入库时效保障

| 运输方式 | KPI要求 | 飞力达目标 | 保障措施 |
|---------|---------|-----------|---------|
| 空运（PVG→临港） | 12小时内完成，99% | 10小时内完成，99.5% | 专人驻场机场，优先清关通道 |
| 海运（洋山港→临港） | 36小时内完成，99% | 30小时内完成，99.5% | 预录入提前完成，港内直拖 |

**时效保障措施：**
1. **航班/船期提前获取**：与PCN、清关行建立信息共享，提前获取航班/船期信息
2. **绿色通道**：预申报提前完成，货物到港后优先理货，缩短等待时间
3. **专车直送**：空运货物到港后由专车（≤1.5吨小货车）直送仓库，无需二次中转
4. **夜间/节假日运营**：仓库7×24小时运营，夜间及节假日正常处理入库
5. **SAP EWM实时监控**：入库各环节时间戳记录，临近SLA时自动预警

#### 4.1.3 验收标准

| 检查项目 | 操作标准 | 不合格处理 |
|---------|---------|-----------|
| 外观检查 | 100%目视检查外包装，拍照留存 | 破损拒收或异常签收，通知PCN |
| 数量清点 | 按件/按箱清点，系统扫码比对 | 短溢报告，24小时内反馈 |
| 单据核对 | 核对件数/重量/零件号与ASN一致性 | 差异启动调查流程 |
| 温控货物 | 温度记录仪检查，数据下载存档 | 超温拒收或隔离存放，通知供应商 |

### 4.2 存储与拣货流程

#### 4.2.1 存储策略

| 存储原则 | 具体方案 |
|---------|---------|
| ABC分类管理 | A类（高价值/VOR零件）：最优库位；B类：中间层；C类：高层/远端 |
| 最近可用（Near-to-pick） | 高频拣货零件放置于最近拣货区，减少行走时间 |
| 先进先出（FIFO） | 系统强制FIFO出库策略，库位标签注明入库日期 |
| 批次管理 | 同一批次零件优先出库，批次标签全程追溯 |
| 库位编码 | 采用"区-排-列-层-位"6位编码（如A-01-03-02-B），扫描即可精确定位 |

#### 4.2.2 拣货流程

```
EWM系统生成波次计划 ──▶ 拣货任务分配 ──▶ 拣货员领取任务（扫描枪）
                                    │
                    ┌───────────────┴───────────────┐
                    ▼                               ▼
            【整箱拣货】                       【拆零拣货】
            直接出库暂存区                     拣货小车/周转箱
                    │                               │
                    └───────────────┬───────────────┘
                                    ▼
                            拣货完成，扫描确认
                                    │
                                    ▼
                            出库暂存区集货
                                    │
                                    ▼
                            出库复核（VOR优先处理）
```

**拣货模式：**
- **区域拣货（Zone Picking）**：将仓库分为若干区域，多人并行拣货，缩短拣货时间
- **波次组合**：VOR订单独立波次，实时触发，优先处理；库存订单批次波次，攒单处理
- **RF扫描全程追溯**：每个拣货动作均有时间戳和操作员记录，满足盘点追溯要求

### 6.2 配送准确率99.97%的保障措施

配送准确率是PCN最核心的KPI之一，飞力达从以下五个维度建立立体化保障体系：

#### 第一重：出库三重复核
1. **拣货复核**：拣货员拣货后扫描零件条码，系统自动比对订单明细
2. **打包复核**：打包员再次扫描出库零件，与配送单逐行核对
3. **出库复核**：出库管理员最终复核件数/重量/目的地，签收确认

#### 第二重：全程条码追溯
- 每个零件粘贴唯一序列号标签
- 入库、上架、拣货、出库、签收全程扫码记录
- 任何环节扫码异常立即触发预警

#### 第三重：VOR零件优先处理
- VOR零件设立专属暂存区，与普通库存物理分离
- VOR出库优先波次、优先拣货、优先复核、优先装载
- VOR订单全程时间戳管理，异常5分钟内升级

#### 第四重：承运商KPI管理
- 承运商准入门槛：5年以上汽车零件配送经验，货损率<0.1%
- 承运商月度KPI考核：准时率、货损率、签收率三维度评分
- 末位淘汰：连续3个月排名末位，终止合作

#### 第五重：签收与异常管理
- 送货时要求收件人当场清点并签字确认
- 签收单拍照上传系统，24小时内归档
- 签收差异24小时内启动调查，48小时内给PCN反馈

### 6.3 货损率0%的控制手段

| 货损来源 | 控制手段 |
|---------|---------|
| 运输震动/冲击 | 厢式货车+减震设备，精密零件使用防震包装，装载高度限制 |
| 堆叠压损 | 栈板堆叠不超过2.5m，高价值零件单独堆叠，重量分布均匀 |

| 包装破损 | 入库100%检查外包装，拍照留存；出库使用原厂包装或等效包装 |
| 叉车操作 | 叉车操作员持证上岗，限速5km/h（室内），设置叉车作业区域 |
| 拣货错误 | RF扫描全程比对，系统强制校验，拣货与复核分离 |
| 交接丢失 | 交接清单双方签字确认，扫描记录实时上传系统 |

### 6.4 库存准确率≤0.02%的管理方法

### 8.4 系统故障应急预案

#### 8.4.1 系统故障分级

| 故障等级 | 影响范围 | 响应时间 | 处置策略 |
|---------|---------|---------|---------|
| 一级（重大） | SAP EWM完全不可用 | 15分钟内响应 | 启动人工模式，保障出库，人工记录后补录系统 |
| 二级（较大） | 部分功能不可用 | 30分钟内响应 | 启用备用功能，人工替代处理 |
| 三级（一般） | 单点故障，不影响主流程 | 2小时内响应 | 逐步修复，影响可控 |

#### 8.4.2 SAP EWM系统故障应急流程

```
系统故障发现/报告
        │
        ▼ 5分钟内
IT工程师确认故障范围，判定等级
        │
        ├── 【一级故障】
        │    ▼ 立即通知PCN IT
        │    ▼ 通知项目总监
        │    ▼ 启动人工模式
        │    │
        │    ├── 出库：手工单据+电话确认+拍照留档
        │    ├── 入库：手工登记+补录系统
        │    └── 拣货：纸质任务单+手写记录
        │
        ├── 【二/三级故障】
        │    ▼ 联系PCN IT确认预计恢复时间
        │    ▼ 切换至备用网络/设备
        │
        ▼ 30分钟内
定期向PCN IT更新故障进展
        │
        ▼ 系统恢复后
立即补录所有人工记录（优先VOR订单）
系统数据一致性核查
差异报告（如有）
```

#### 8.4.3 人工模式保障措施

- **手工单据储备**：仓库常备足量手工出库单、入库单、拣货单模板
- **电话/微信确认机制**：VOR订单通过电话双向确认，录音存档
- **影像记录**：关键操作拍照/视频留存，作为系统补录依据
- **定期演练**：每季度模拟一次系统故障应急演练，确保人员熟悉人工操作流程
