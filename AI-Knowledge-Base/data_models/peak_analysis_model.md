# 峰值分析模型

> 本文件用于指导 Data Analyst Agent 分析业务峰值

---

## 一、峰值分析概述

### 1.1 峰值类型
| 类型 | 触发原因 | 周期 | 峰值倍数 |
|------|---------|------|---------|
| 日峰值 | 特定时段 | 每天 | 1.5-2x |
| 周峰值 | 工作日/周末 | 每周 | 1.2-1.5x |
| 月峰值 | 月末/月初 | 每月 | 1.3-1.8x |
| 季峰值 | 淡旺季 | 每季 | 1.5-3x |
| 大促峰值 | 618/双11等 | 每年 | 3-10x |

### 1.2 峰值系数定义
```
峰值系数 = 峰值业务量 / 平均业务量
```

---

## 二、峰值分析方法

### 2.1 时间序列分析
```
日峰值分析：
- 统计每日订单量
- 识别日最高点
- 计算日峰值系数

周峰值分析：
- 统计每日/每周订单量
- 识别周峰值日
- 分析周内分布

月峰值分析：
- 统计每月订单量
- 识别月峰值月
- 计算月峰值系数
```

### 2.2 大促峰值分析
```python
# 大促峰值预测模型
def predict_peak(order_base, promo_factor):
    peak_order = order_base * promo_factor
    # 峰值订单量 = 基础订单量 × 活动系数
    return peak_order
```

### 2.3 峰值特征分析
| 特征 | 日常 | 大促 |
|------|------|------|
| 峰值时间 | 集中在某时段 | 全天相对均匀 |
| 峰值倍数 | 1.5-2x | 5-10x |
| 峰值持续 | 2-4小时 | 24-72小时 |
| 订单结构 | 正常 | 多爆款 |

## 四、峰值预测模型

### 4.1 简单移动平均
```
预测值 = (T-1 + T-2 + T-3 + ... + T-n) / n
```

### 4.2 趋势调整
```
预测值 = 基础预测 × 季节系数 × 趋势系数
```

### 4.3 大促预测
```python
# 大促订单预测
def predict_promo(base_orders, promo_days, historical_multiplier):
    avg_daily = base_orders
    peak_day_multiplier = max(historical_multiplier)  # 历年峰值倍数
    total_promo_orders = avg_daily * promo_days * peak_day_multiplier
    return total_promo_orders
```

## 五、峰值应对策略

### 5.1 人员应对
| 峰值等级 | 人员策略 | 响应时间 |
|---------|---------|---------|
| <1.5x | 正常排班+加班 | 1天 |
| 1.5-2x | 加班+临时工 | 3天 |
| 2-3x | 招聘临时工+外包 | 1周 |
| >3x | 启动外包+跨区支援 | 2周 |

### 5.2 设备应对
| 峰值等级 | 设备策略 |
|---------|---------|
| <1.5x | 正常配置 |
| 1.5-2x | 租赁设备 |
| 2-3x | 增加设备+外包 |
| >3x | 设备最大化+跨区调用 |
