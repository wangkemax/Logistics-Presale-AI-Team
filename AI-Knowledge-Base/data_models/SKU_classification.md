## 三、分析方法

### 3.1 帕累托分析
```
步骤：
1. 计算各SKU的销售额贡献
2. 按销售额降序排列
3. 计算累计销售额占比
4. 识别80%销售的关键SKU
```

### 3.2 周转分析
```
周转次数 = 年销售量 / 平均库存
周转天数 = 365 / 周转次数
```

### 3.3 库存年龄分析
```
库龄 = 当前日期 - 入库日期
长库龄SKU = 库龄 > 90天
呆滞SKU = 库龄 > 180天无动弹
```
