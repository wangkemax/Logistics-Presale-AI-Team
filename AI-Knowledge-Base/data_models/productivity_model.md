## 一、人效指标体系

### 1.1 基础人效指标
| 指标 | 计算公式 | 单位 | 说明 |
|------|---------|------|------|
| 人均订单量 | 总订单数/总人数 | 单/人 | 综合人效 |
| 人均拣货量 | 总拣货行数/人数 | 行/人 | 拣货效率 |
| 人均出库量 | 总出库件数/人数 | 件/人 | 出库效率 |
| 人均产值 | 总产值/人数 | 万元/人 | 产出价值 |

### 1.2 单位成本指标
| 指标 | 计算公式 | 单位 | 目标 |
|------|---------|------|------|
| 单位人工成本 | 人工总成本/订单数 | 元/单 | 越低越好 |
| 人均人工成本 | 人工总成本/人数 | 万元/人 | 合理范围 |
| 工资坪效 | 销售额/工资总额 | 元/元 | >3 |

## 二、人效计算模型

### 2.1 标准人效计算
```
标准人效 = 理论作业量 / 标准工时
```

### 2.2 实际人效计算
```
实际人效 = 实际作业量 / 实际工时
```

### 2.3 人效达成率
```
人效达成率 = 实际人效 / 标准人效 × 100%
```

## 三、人效影响因素

### 3.1 业务因素
| 因素 | 影响方向 | 说明 |
|------|---------|------|
| 订单复杂度 | 负向 | SKU越多，人效越低 |
| 拣货距离 | 负向 | 仓库越大，人效越低 |
| 自动化程度 | 正向 | 自动化↑人效↑ |
| 季节性波动 | 波动 | 旺季人效高，淡季低 |

### 3.2 管理因素
| 因素 | 影响方向 | 说明 |
|------|---------|------|
| 排班合理性 | 正向 | 匹配峰谷 |
| 培训程度 | 正向 | 熟练度↑人效↑ |
| 激励机制 | 正向 | 绩效挂钩 |
| 流程优化 | 正向 | 减少浪费 |

## 五、人效优化建议

### 5.1 短期优化(1个月内)
- 优化拣货路径
- 调整排班匹配峰谷
- 加强新员工培训
- 完善绩效考核

### 5.2 中期优化(1-3个月)
- 引入辅助工具/设备
- 优化仓库布局
- 改善作业流程
- 建立人效看板

### 5.3 长期优化(3个月以上)
- 评估自动化可行性
- 引入AGV/分拣设备
- 建立人效标杆
- 持续改进机制

### 6.2 差距分析
```
人效差距 = 实际人效 - 标杆人效
差距比例 = (实际人效 - 标杆人效) / 标杆人效 × 100%
```
