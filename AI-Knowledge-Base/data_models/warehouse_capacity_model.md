# 仓库容量模型

> 本文件用于指导 Data Analyst Agent 分析仓库容量

---

## 一、容量指标体系

### 1.1 容量指标
| 指标 | 定义 | 计算公式 | 单位 |
|------|------|---------|------|
| 总面积 | 仓库总建筑面积 | - | m² |
| 可用面积 | 实际可用面积 | 总面积-公摊 | m² |
| 存储面积 | 货架/货区面积 | 可用面积-通道 | m² |
| 存储容量 | 最大存储量 | 库位数×单容量 | 托/m³ |
| 利用率 | 实际使用/可用 | 存储量/容量×100% | % |

### 1.2 容量评估公式
```
面积利用率 = 存储面积 / 可用面积 × 100%

容积率 = 实际存储量 / 存储容量 × 100%

库位数利用率 = 已用库位数 / 总库位数 × 100%
```

---

## 二、容量规划模型

### 2.1 需求预测
```
所需库位数 = 日均库存量 / 单库位存储量 × 安全系数
```

### 2.2 面积计算
```
所需面积 = 所需库位数 × 单库位面积 + 通道面积 + 公摊面积
```

### 2.3 安全系数
| 业务类型 | 建议安全系数 | 说明 |
|---------|------------|------|
| 稳定业务 | 1.1-1.2 | 正常波动 |
| 波动业务 | 1.2-1.3 | 季节性波动 |
| 高增长业务 | 1.3-1.5 | 预留扩展 |

## 四、容量预警

### 4.1 预警等级
| 等级 | 利用率 | 预警措施 |
|------|--------|---------|
| 绿色 | 0-70% | 正常运营 |
| 黄色 | 70-85% | 关注补货节奏 |
| 橙色 | 85-95% | 启动扩容准备 |
| 红色 | >95% | 立即扩容 |

### 4.2 扩容方案
| 方案 | 适用情况 | 成本 | 周期 |
|------|---------|------|------|
| 优化布局 | 利用率<90% | 低 | 短 |
| 增加货架 | 中期扩容 | 中 | 中 |
| 仓库扩建 | 长期扩容 | 高 | 长 |
| 租赁新仓 | 紧急扩容 | 高 | 短 |
