# 订单画像分析模型

> 本文件用于指导 Data Analyst Agent 分析订单特征

---

## 一、订单数据结构

### 1.1 订单基础字段
| 字段 | 说明 | 分析用途 |
|------|------|---------|
| 订单号 | 唯一标识 | 订单追溯 |
| 订单日期 | 下单时间 | 时间分析 |
| 客户名称 | 客户标识 | 客户分析 |
| 订单类型 | B2B/B2C/BC | 业务分类 |
| 订单状态 | 待处理/已完成 | 状态分析 |
| 收货地址 | 配送目的地 | 区域分析 |

### 1.2 订单明细字段
| 字段 | 说明 | 分析用途 |
|------|------|---------|
| SKU | 商品编码 | SKU分析 |
| 数量 | 订购数量 | 批量分析 |
| 单价 | 商品单价 | 价格分析 |
| 金额 | 订单金额 | 价值分析 |

## 二、订单特征分析

### 2.1 订单量分布
| 指标 | 定义 | 分析价值 |
|------|------|---------|
| 日均订单量 | 订单数/天数 | 产能规划 |
| 峰值订单量 | 最大单日订单 | 弹性能力 |
| 峰值倍数 | 峰值/均值 | 波动系数 |
| 订单集中度 | top时段/总订单 | 削峰需求 |

### 2.2 订单结构分析
| 分析维度 | 指标 | 说明 |
|---------|------|------|
| 订单行数 | 分布区间 | 复杂度 |
| 单量分布 | 1件/2-5件/5+件 | 打包策略 |
| 订单金额 | 分布区间 | 客单价 |
| SKU数 | 单均SKU数 | 拣货效率 |

### 2.3 订单时效分析
| 时效指标 | 定义 | 目标 |
|---------|------|------|
| 截单时间 | 当日订单截止时间 | 设定时间点 |
| 履约周期 | 截单到签收 | ≤48h |
| 发货及时率 | 按时发货/总订单 | ≥99% |
| 配送及时率 | 按时到达/总订单 | ≥98% |

## 四、客户维度分析

### 4.1 客户分层
| 客户层级 | 定义 | 订单特征 |
|---------|------|---------|
| 大客户 | TOP 10% | 大批量/稳定 |
| 中客户 | 中间70% | 中等批量/波动 |
| 小客户 | 底20% | 小批量/零散 |

### 4.2 客户贡献度
```
客户贡献度 = 客户订单金额 / 总订单金额 × 100%
```

### 4.3 客户复购分析
| 指标 | 定义 | 目标值 |
|------|------|-------|
| 复购率 | 重复购买客户/总客户 | 越高越好 |
| 平均复购周期 | 天数 | 越短越好 |
| 客户留存率 | 留存客户/上期客户 | ≥80% |
