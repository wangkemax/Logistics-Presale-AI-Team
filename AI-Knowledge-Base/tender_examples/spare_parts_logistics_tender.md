- **业务模式**：保内/保外/混合

### 1.2 备件物流特点
| 特点 | 说明 | 我方应对 |
|------|------|---------|
| 应急性 | 停机损失大 | 7×24小时响应 |

4. **成本**：合理价格

## 二、备件仓储方案

### 2.1 仓库布局
```
[仓库布局图]

收货区 → 质检区 → 存储区(按品类) → 拣货区 → 发货区
                                          ↓
                              退货区(维修/报废)
```

### 2.2 存储策略
| 备件类型 | 存储方式 | 管理重点 |
|---------|---------|---------|
| 常用件 | 高位货架 | 易于拣选 |
| 慢用件 | 低位存储 | 定期盘点 |
| 危化件 | 独立存放 | 安全规范 |
| 维修件 | 专区 | 流程追溯 |

### 2.3 库存管理
- **安全库存**：高频件设置动态安全库存
- **补货策略**：按消耗自动触发补货
- **效期管理**：橡胶/化学品优先FIFO
- **盘点机制**：常用件日盘，慢用件月盘

## 三、配送方案

### 3.1 配送网络
```
中心仓(RDC) → 区域仓(SDC) → 服务站/门店 → 客户
      ↓
   紧急通道(7×24h)
```

### 3.2 配送时效标准
| 服务类型 | 时效承诺 | 说明 |
|---------|---------|------|
| 紧急配送 | 4小时内 | 7×24h |
| 标准配送 | 次日达 | 省会城市 |
| 普通配送 | 2-3日达 | 乡镇地区 |
| 计划配送 | 按约定 | 批量备货 |

### 3.3 配送模式
| 模式 | 适用场景 | 成本 |
|------|---------|------|
| 专车直送 | 紧急/批量 | 高 |
| 快递 | 小件/散件 | 中 |
| 区域配送 | 常规补货 | 低 |
| 带回程 | 优化成本 | 低 |
