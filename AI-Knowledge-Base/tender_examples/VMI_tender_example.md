## 二、VMI服务方案

### 2.1 服务范围
| 服务项 | 内容 | 范围 |
|--------|------|------|
| 收货管理 | 供应商送货接收 | |
| 质检管理 | IQC检验 | |
| 仓储管理 | VMI库存存储 | |
| 订单处理 | 客户订单响应 | |
| 出库配送 | 线边仓配送 | |
| 数据管理 | 库存数据共享 | |

### 2.2 服务模式
```
供应商送货 → VMI仓库收货 → IQC检验 → 入库存储
                                       ↓
客户订单 → 库存锁定 → 拣货集货 → 出库配送 → 线边仓
                                       ↓
                            消耗确认 → 数据同步 → 结算对账
```

### 2.3 运作流程

#### 入库流程
1. 供应商送货到VMI仓库
2. ASN预登记，系统核验
3. 来货卸货与单据核对
4. IQC检验（按抽检标准）
5. 合格品入库上架
6. 系统库存更新，通知客户

#### 出库流程
1. 接收客户要货计划/订单
2. 库存分配，锁定库存
3. 拣货集货
4. 出库复核
5. 配送至客户线边仓
6. 客户确认签收
7. 消耗数据同步

## 三、库存管理方案

### 3.1 库存策略
| SKU分类 | 管理策略 | 补货方式 |
|---------|---------|---------|
| A类(高周转) | 重点管理 | 自动补货 |
| B类(中周转) | 常规管理 | 定期补货 |
| C类(低周转) | 简化管理 | 按需补货 |

### 3.2 安全库存设置
```
安全库存 = (最大日耗 - 平均日耗) × 补货周期
```

### 3.3 补货机制
- **触发条件**：库存≤安全库存
- **补货量**：最高库存 - 当前库存
- **响应时效**：24小时内补货

### 3.4 库存报表
| 报表类型 | 频率 | 内容 |
|---------|------|------|
| 实时库存 | 实时 | 当前库存 |
| 库龄分析 | 周 | 按库龄分布 |
| 呆滞预警 | 周 | 超期预警 |
| 消耗预测 | 月 | 未来需求 |
