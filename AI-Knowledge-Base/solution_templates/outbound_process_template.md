# 出库流程模板

> 标准化出库流程，适用于各类仓储项目

---

## 出库流程总览

```
订单接收 → 订单审核 → 库存分配 → 拣货 → 复核 → 打包 → 交接出库 → 完成出库
```

---

## 各环节详细说明

### 环节1：订单接收
**职责**：客服组 / 系统自动

**接收渠道**：
| 渠道 | 接收方式 | 订单格式 |
|------|---------|---------|
| ERP对接 | API/文件 | XML/JSON |
| 电商平台 | API | JSON |
| 邮件/传真 | 人工 | Excel/PDF |
| 客户Portal | 手工录入 | Web表单 |

**操作**：
1. 接收订单
2. 订单有效性检查
3. 异常订单标记
4. 订单状态更新

**系统操作**：OMS→WMS订单同步

---

### 环节2：订单审核
**职责**：客服组

**审核内容**：
| 审核项 | 检查内容 | 异常处理 |
|--------|---------|---------|
| 库存可用性 | 库存是否足够 | 缺货处理 |
| 地址有效性 | 配送地址是否正确 | 地址确认 |
| 特殊要求 | 是否有特殊备注 | 按备注处理 |
| 信用额度 | 是否超额度 | 额度确认 |
| 法规限制 | 是否有发货限制 | 合规检查 |

**审核结果**：
- **通过**：进入下一环节
- **驳回**：退回客户/重新确认
- **挂起**：等待进一步处理

**交付物**：审核通过订单列表

---

### 环节3：库存分配
**职责**：系统自动 / 仓库主管

**分配策略**：
| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 先进先出(FIFO) | 先入库先出库 | 有有效期商品 |
| 先进先出(LIFO) | 后入库先出库 | 高流转商品 |
| 指定批次 | 指定批次出库 | 客户要求 |
| 接近库位 | 优先分配最近库位 | 提升效率 |

**波次规划**：
| 波次 | 截止时间 | 配送路线 |
|------|---------|---------|
| 波次1 | 08:00 | 华东区 |
| 波次2 | 12:00 | 华南区 |
| 波次3 | 16:00 | 华北区 |

**系统操作**：WMS生成波次单

---

### 环节4：拣货
**职责**：拣货组

**拣货方式**：
| 方式 | 说明 | 适用场景 |
|------|------|---------|
| 摘果式 | 逐单拣货 | 订单分散 |
| 播种式 | 集合拣货后再分 | 订单集中 |
| 边拣边分 | 边拣边按单分配 | 中等批量 |
| 区域接力式 | 分区域拣货接力 | 大型仓库 |

**操作流程**：
1. 领取波次单/RF
2. 按规划路线拣货
3. 扫描商品确认
4. 放入集货位
5. 完成拣货确认

**拣货路径优化**：
```
S型路径 / Z型路径 / 需求密度路径
```

**交付物**：拣货完成集货箱

---

### 环节5：复核
**职责**：复核组

**复核内容**：
| 复核项 | 检查方法 | 允收标准 |
|--------|---------|---------|
| 商品正确性 | 扫描比对 | 100%准确 |
| 数量正确性 | 清点/称重 | ±0 |
| 批次正确性 | FIFO检查 | 符合策略 |
| 包装完整性 | 目视检查 | 无破损 |

**复核方式**：
- [ ] 逐件扫描复核
- [ ] 抽样复核
- [ ] 称重复核

**异常处理**：
| 异常类型 | 处理方式 |
|---------|---------|
| 商品错误 | 重新拣货 |
| 数量不足 | 库存调整 |
| 批次不符 | 调换批次 |

**交付物**：复核通过清单

---

### 环节6：打包
**职责**：打包组

**打包标准**：
| 商品类型 | 包装材料 | 填充物 | 封箱方式 |
|---------|---------|--------|---------|
| 普货 | 纸箱 | 气泡膜/填充纸 | 封箱胶带 |
| 易碎品 | 纸箱+木架 | 泡沫 | 封箱胶带+打包带 |
| 液体 | 防漏包装 | 吸震材料 | 热缩膜+封箱胶带 |

**包装要求**：
- 重量限制：单箱≤30kg
- 体积限制：长+宽+高≤150cm
- 标签要求：收发货信息清晰

**增值服务**：
- [ ] 礼品包装
- [ ] 组装服务
- [ ] 特殊包装

**交付物**：打包完成包裹

---

### 环节7：交接出库
**职责**：仓库 / 快递/物流

**交接流程**：
1. 包裹称重计费
2. 扫描出库
3. 生成运单
4. 与承运商交接
5. 获取交接凭证

**交接清单**：
| 快递单号 | 收件人 | 件数 | 重量 | 目的地 |
|---------|-------|------|------|--------|
|         |       |      |      |        |

**系统操作**：WMS出库确认

## 异常处理流程

```
发现异常 → 记录异常 → 包裹隔离 → 通知责任人 → 处理决定 → 执行处理 → 记录归档
```

### 常见异常
| 异常情况 | 处理方式 | 责任人 |
|---------|---------|--------|
| 缺货 | 订单拆分/延迟 | 客服 |
| 拣货错误 | 重新拣货 | 仓库主管 |
| 复核异常 | 重新复核 | 复核组 |
| 打包破损 | 重新打包 | 打包组 |

## KPI指标

| 指标 | 定义 | 目标值 |
|------|------|-------|
| 出库及时率 | 按时出库订单/总订单 | ≥99% |
| 拣货准确率 | 正确拣货行/总拣货行 | ≥99.9% |
| 复核准确率 | 复核无误单/总复核单 | ≥99.95% |
| 打包合格率 | 合格包裹/总包裹 | ≥99.5% |
| 出库破损率 | 破损件数/出库总件数 | ≤0.05% |
| 48小时出库率 | 48h内出库订单/总订单 | ≥99.5% |
