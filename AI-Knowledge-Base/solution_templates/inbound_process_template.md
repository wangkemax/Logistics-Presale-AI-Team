# 入库流程模板

> 标准化入库流程，适用于各类仓储项目

---

## 入库流程总览

```
供应商送货 → 预约登记 → 来货卸货 → 单据核对 → 来货检验 → 上架入库 → 系统确认 → 完成入库
```

---

## 各环节详细说明

### 环节1：供应商送货
**职责**：供应商 / 承运商

**操作**：
1. 按送货计划安排送货
2. 随车携带送货单据
3. 车辆到达仓库月台

**交付物**：
- 送货单
- 装箱单
- 质检报告（如有）

---

### 环节2：预约登记
**职责**：收货组 / 门卫

**操作**：
1. 核对供应商信息
2. 确认送货单号
3. 登记车辆信息
4. 分配卸货月台

**交付物**：入库预约单

**系统操作**：WMS录入预约信息

---

### 环节3：来货卸货
**职责**：搬运组

**操作**：
1. 车辆引导至指定月台
2. 核对箱数/件数
3. 规范卸货，防止破损
4. 异常件单独存放

**注意事项**：
- 轻拿轻放
- 按批次分开
- 危化品按规范操作

**交付物**：卸货记录

---

### 环节4：单据核对
**职责**：收货组

**操作**：
1. 核对送货单与系统订单
2. 核对SKU数量
3. 核对包装规格
4. 确认批号/生产日期

**异常处理**：
| 异常类型 | 处理方式 |
|---------|---------|
| 单据不符 | 暂存，待确认 |
| 数量差异 | 差异单记录 |
| 包装破损 | 拍照留存 |

**交付物**：核对结果记录

---

### 环节5：来货检验(IQC)
**职责**：质检组

**检验项目**：
| 检验类型 | 检验内容 | 抽样比例 |
|---------|---------|---------|
| 外观检验 | 破损、污渍 | 5% |
| 数量检验 | 清点数量 | 100% |
| 标签检验 | 标签正确性 | 10% |
| 功能检验 | 如有 | 抽检 |

**判定标准**：
- **合格**：允许入库
- **不合格**：退货/降价接受
- **待定**：隔离存放，复检

**交付物**：IQC检验报告

**系统操作**：WMS录入检验结果

---

### 环节6：上架入库
**职责**：上架组

**上架策略**：
- **定位存放**：指定库位
- **随机存放**：有空位即放
- **分类存放**：按品类/ABC分类

**操作流程**：
1. 领取RF终端
2. 扫描库位条码
3. 扫描商品条码
4. 确认上架数量
5. 系统过账

**库位选择规则**：
| 商品类型 | 存放区域 | 规则 |
|---------|---------|------|
| A类商品 | 靠近出库区 | 高周转 |
| B类商品 | 中间区域 | 中周转 |
| C类商品 | 远离出库区 | 低周转 |

**交付物**：上架完成确认

---

### 环节7：系统确认
**职责**：收货组 / 系统自动

**操作**：
1. 系统生成入库单
2. 库存更新
3. 单据归档
4. 通知相关方

**系统操作**：WMS完成入库过账

## 异常处理流程

```
发现异常 → 记录异常 → 拍照留存 → 通知责任人 → 处理决定 → 执行处理 → 记录归档
```

### 常见异常及处理
| 异常情况 | 处理方式 | 责任人 |
|---------|---------|--------|
| 单据不符 | 联系供应商确认 | 收货主管 |
| 数量差异 | 差异单处理 | 收货组 |
| 包装破损 | 拍照，通知供应商 | 质检组 |
| 品质异常 | 隔离，复检或退货 | 质检组 |
| 系统故障 | 手工记录，后补录入 | IT / 收货组 |

| 入库及时率 | 按时入库次数/总入库次数 | ≥98% |
| 单据准确率 | 准确单据数/总单据数 | ≥99.5% |
| 检验合格率 | 合格批次/总批次 | ≥95% |
| 上架准确率 | 上架准确库位数/总上架库位 | ≥99.9% |
| 入库破损率 | 破损件数/入库总件数 | ≤0.05% |
