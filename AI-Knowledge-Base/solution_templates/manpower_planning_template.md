> 标准化人力规划模板，适用于仓储项目人员配置

---

## 一、配置原则

### 基本原则
1. **效率导向**：按订单量/工作量配置人数
2. **弹性配置**：灵活应对峰谷波动
3. **岗位精简**：一人多岗，降低成本
4. **培训通用**：基础技能通用化
5. **排班合理**：保障员工休息，控制加班

## 四、人力配置计算

### 计算公式

**基本配置人数**：
```
配置人数 = 日均订单量 / 人效指标
```

**峰值配置人数**：
```
峰值人数 = 日均人数 × 峰值系数
```

**临时工需求**：
```
临时工 = (峰值人数 - 基准人数) × 峰值天数占比
```

### 计算示例
```
日均订单：2000单
人效指标：100单/人/天
基准人数：2000/100 = 20人
峰值系数：1.5
峰值人数：20 × 1.5 = 30人
临时工需求：10人
```

## 七、加班与临时工管理

### 加班管理
- 月加班上限：36小时/人
- 加班申请：提前1天审批
- 加班费：平日150%，周末200%，法定300%

### 临时工管理
| 项目 | 说明 |
|------|------|
| 招聘渠道 | 劳务外包 / 临时工平台 |
| 提前通知 | 旺季前3-5天预约 |
| 培训要求 | 上岗前培训2小时 |
| 管理方式 | 与正式工同标准管理 |
| 结算方式 | 按小时/按天结算 |
