# 库存管理模板

> 标准化库存管理方案，适用于各类仓储项目

---

## 库存管理策略总览

```
入库管理 → 存储管理 → 盘点管理 → 补货管理 → 出库管理 → 数据分析
```

---

## 一、库位管理

### 1.1 库位编码规则
**编码结构**：`{仓库区}-{货架排}-{货架层}-{库位}`

**示例**：`A-01-03-02` = A区01排03层02号位

### 1.2 库位分类
| 类型 | 代码 | 用途 | 特点 |
|------|------|------|------|
| 收货暂存区 | STG | 入库待检 | 流动性高 |
| 存储区 | STR | 正式存储 | 按策略分类 |
| 拣货区 | PIC | 拣货暂存 | 高周转 |
| 集货区 | COL | 集货待发 | 流动性高 |
| 退货区 | RTN | 退货物 | 待处理 |
| 报废区 | SCR | 报废品 | 待处理 |
| 隔离区 | HLD | 异常品 | 待确认 |

### 1.3 库位状态
| 状态 | 说明 | 可用性 |
|------|------|--------|
| 空 | 无库存 | 可用 |
| 占用 | 有库存 | 不可用 |
| 冻结 | 锁定状态 | 不可用 |
| 维护 | 维护中 | 不可用 |

## 五、盘点管理

### 5.1 盘点类型
| 类型 | 频率 | 方式 | 范围 |
|------|------|------|------|
| 日循环盘点 | 每日 | 按计划滚动盘点 | A类商品 |
| 周盘点 | 每周 | 全库位 | B类商品 |
| 月盘点 | 每月 | 全面盘点 | 所有商品 |
| 专项盘点 | 按需 | 指定区域/SKU | 异常区域 |

### 5.2 盘点流程
```
盘点计划 → 冻结库存 → 盘点执行 → 数据录入 → 差异核对 → 审批调整 → 差异处理 → 完成
```

### 5.3 盘点允许差异率
| SKU分类 | 允许差异率 |
|---------|-----------|
| A类 | ≤0.05% |
| B类 | ≤0.1% |
| C类 | ≤0.2% |

### 5.4 盘点差异处理
| 差异金额 | 处理方式 |
|---------|---------|
| ≤100元 | 仓库主管审批 |
| 100-1000元 | 仓库经理审批 |
| >1000元 | 财务审批 |

## 六、补货管理

### 6.1 补货触发机制
| 触发方式 | 条件 | 适用场景 |
|---------|------|---------|
| 定量补货 | 库存≤安全库存 | 常规补货 |
| 定期补货 | 每周固定时间 | 稳定需求 |
| 动态补货 | 按实际消耗 | 高波动需求 |
| 订单驱动 | 订单发生时 | JIT场景 |

### 6.2 安全库存计算
**公式**：
```
安全库存 = (最大日销量 - 平均日销量) × 补货提前期
```

**变量说明**：
- 最大日销量：过去30天最大单日销量
- 平均日销量：过去30天平均单日销量
- 补货提前期：从下单到到货的天数

### 6.3 补货点计算
**公式**：
```
补货点 = 平均日销量 × 补货提前期 + 安全库存
```

### 6.4 补货量计算
**公式**：
```
补货量 = 最高库存 - 当前库存
```
或
```
补货量 = (平均日销量 × 补货周期) - 当前库存
```

## 七、库存分析

### 7.1 常规报表
| 报表名称 | 频率 | 内容 |
|---------|------|------|
| 库存台账 | 每日 | 实时库存明细 |

| 库存账龄 | 每月 | 按入库时长分布 |

### 7.2 呆滞库存定义
| 库龄 | 定义 | 处理建议 |
|------|------|---------|
| 30天内 | 正常 | 无需处理 |
| 30-90天 | 关注 | 促销消化 |
| 90-180天 | 预警 | 降价处理 |
| >180天 | 呆滞 | 报废/捐赠 |

## 八、KPI指标

| 指标 | 计算方式 | 目标值 |
|------|---------|-------|
| 库存准确率 | (账面库存-差异)/账面库存 | ≥99.5% |
| 盘点准确率 | 盘点相符项/盘点总项 | ≥99.9% |
| 库存周转天数 | 平均库存/日均出库量 | 按品类设定 |
| 呆滞库存占比 | 呆滞库存/总库存 | ≤5% |
| 现货率 | 有货订单/总订单 | ≥99% |
| 库存周转率 | 年出库量/平均库存 | 按品类设定 |
