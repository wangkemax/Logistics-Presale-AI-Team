## 二、库存管理最佳实践

### 2.1 库存策略框架
```
需求预测 → 安全库存 → 补货策略 → 库存可视 → 持续优化
```

### 2.2 关键库存指标
| 指标 | 计算公式 | 目标值 |
|------|---------|-------|
| 库存周转天数 | 365/周转率 | 按品类设定 |
| 现货率 | 有货订单/总订单 | ≥99% |
| 呆滞库存率 | 呆滞库存/总库存 | ≤3% |
| 盘点准确率 | 准确项/盘点项 | ≥99.9% |

### 2.3 安全库存计算
```
安全库存 = (最大日耗 - 平均日耗) × 补货周期
```
