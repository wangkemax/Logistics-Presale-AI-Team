# 人工成本模型

> 服务于 Cost Model Agent，用于自动测算仓储项目人工成本

---

## 一、成本结构

### 1.1 人工成本组成
| 成本项 | 说明 | 占比参考 |
|--------|------|---------|
| 基本工资 | 员工基本薪酬 | 60-70% |
| 加班费 | 超出正常工时的报酬 | 5-15% |
| 社保公积金 | 法定义务 | 20-30% |
| 餐补/交通补贴 | 福利补贴 | 3-5% |
| 招聘培训费 | 招募和培训成本 | 2-5% |
| 奖金/绩效 | 绩效激励 | 0-10% |
| 临时工成本 | 旺季补充 | 波动 |

### 1.2 人工成本计算公式

**月度人工总成本**：
```
月度人工总成本 = Σ(各岗位人数 × 该岗位月成本)
```

**单岗位月成本**：
```
单岗位月成本 = 基本工资 + 社保公积金 + 补贴 + 加班费 + 绩效奖金
```

## 二、变量定义

| 变量 | 符号 | 说明 | 单位 | 典型取值 |
|------|------|------|------|---------|
| 员工人数 | N | 各岗位人数 | 人 | 依配置 |
| 月均基本工资 | S_base | 税前工资 | 元/月 | 3000-8000 |
| 社保公积金比率 | R_ins | 社保+公积金 | % | 30-35% |
| 餐补标准 | S_meal | 每日餐补 | 元/天 | 20-30 |
| 交通补贴 | S_trans | 每月交通补贴 | 元/月 | 0-500 |
| 月均加班时数 | H_ot | 人均月加班 | 小时 | 0-40 |
| 加班费率 | R_ot | 平日加班 | 倍 | 1.5x |
| 月工作天数 | D | 月计薪日 | 天 | 21.75 |
| 招聘成本/人 | C_rec | 招聘费用 | 元/人 | 500-2000 |
| 培训成本/人 | C_train | 培训费用 | 元/人 | 200-500 |

---

## 三、核心计算模型

### 3.1 单人月成本计算
```
月成本 = S_base × (1 + R_ins) + S_meal × D + S_trans + (H_ot × S_base/174 × R_ot)
```

**说明**：
- 174为月标准工时（21.75天×8小时）
- 加班费按基本工资的1/174计算

### 3.2 日均订单量与人数关系
```
需求人数 = 日均订单量 / 人效指标
```

**人效指标参考**：
| 业务类型 | 人效(单/人/天) | 说明 |
|---------|--------------|------|
| 电商B2C | 100-200 | 取决于自动化程度 |
| B2B批发 | 50-100 | 多SKU整进整出 |
| 制造业原料 | 80-150 | 批量作业 |
| 零部件VMI | 30-80 | 拣选复杂度高 |

### 3.3 月度人工成本计算
```
月度人工成本 = Σ(岗位人数 × 该岗位月成本) × (1 + R_management)
```

**管理费用系数**（R_management）：
- 小型仓库(10人以下)：10-15%
- 中型仓库(10-50人)：8-12%
- 大型仓库(50人以上)：5-8%

---

## 四、加班成本计算

### 4.1 月度加班成本
```
月加班成本 = Σ[人数 × (月均加班时数 × 时薪 × 加班费率)]
```

**时薪计算**：
```
时薪 = 月基本工资 / 174
```

### 4.2 加班费计算
| 时段 | 费率 | 说明 |
|------|------|------|
| 平日加班 | 1.5x | 工作日超出8小时 |
| 周末加班 | 2.0x | 周六周日 |
| 法定节假日 | 3.0x | 法定假期 |

### 4.3 加班预算公式
```
月加班预算 = 月度工资总额 × 加班预算比例
```
**参考比例**：5-15%（取决于业务波动性）

---

## 五、临时工成本计算

### 5.1 临时工月成本
```
临时工月成本 = 临时工人数 × 日工资 × 实际工作天数
```

### 5.2 临时工需求计算
```
临时工需求 = (峰值人数 - 基准人数) × 峰值天数占比
```

### 5.3 临时工与正式工对比
| 项目 | 正式工 | 临时工 |
|------|--------|--------|
| 月均成本 | 较高(5000-10000) | 较低(按天结算) |
| 灵活性 | 低 | 高 |
| 管理成本 | 低 | 较高 |
| 适用场景 | 稳定业务 | 季节性峰值 |

## 六、完整计算示例

### 示例：电商B2C仓储项目
```
基础参数：
- 日均订单：2000单
- 峰值订单：4000单
- 人效指标：120单/人/天
- 基准工资：5000元/月
- 社保比率：32%
- 餐补：20元/天，月21.75天
- 月工作天数：21.75天

计算：
1. 基准人数 = 2000 / 120 = 16.67 ≈ 17人
2. 峰值人数 = 4000 / 120 = 33.33 ≈ 34人
3. 临时工需求 = 34 - 17 = 17人

4. 正式工月成本/人：
   = 5000 × 1.32 + 20×21.75
   = 6600 + 435
   = 7035元/月/人

5. 月度人工成本(正式工)：
   = 17 × 7035 = 119,595元

6. 临时工月成本(假设日均150元)：
   = 17 × 150 × 21.75 = 55,462元

7. 管理费用(假设12%)：
   = (119,595 + 55,462) × 12% = 21,007元

8. 月度人工总成本：
   = 119,595 + 55,462 + 21,007 = 196,064元

9. 单位人工成本：
   = 196,064 / 2000 = 98元/单
```

## 七、成本优化建议

### 7.1 降低人工成本的途径
| 措施 | 预期效果 | 实现方式 |
|------|---------|---------|
| 提高自动化 | 减少20-40%人工 | 引入AGV/分拣设备 |
| 弹性用工 | 降低10-15% | 灵活用工+外包 |
| 提高人效 | 降低10-20% | 布局优化+培训 |
| 错峰排班 | 降低5-10% | 高峰前储备 |
| 减少加班 | 降低5-15% | 合理配置人数 |

### 7.2 成本警戒线
| 指标 | 正常范围 | 预警值 | 处理措施 |
|------|---------|-------|---------|
| 单位人工成本 | 目标值±10% | 超15% | 启动成本分析 |
| 加班率 | ≤10% | >15% | 增加人员 |
| 临时工占比 | ≤20% | >30% | 调整配置 |
| 离职率 | ≤5%/月 | >8%/月 | 留存激励 |
