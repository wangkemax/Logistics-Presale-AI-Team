# 自动化ROI模型

> 服务于 Cost Model Agent，用于评估仓储自动化投资回报

---

## 一、ROI模型概述

### 1.1 核心公式

**投资回收期**：
```
回收期(年) = 总投资成本 / 年均成本节约
```

**年投资回报率(ROI)**：
```
ROI = (年均净收益 / 总投资成本) × 100%
```

**5年净收益**：
```
5年净收益 = 5年总收益 - 总投资成本 - 5年运营维护成本
```

### 2.1 投资成本(CAPEX)
| 成本项 | 说明 | 典型占比 |
|--------|------|---------|
| 设备采购 | 设备购置费 | 60-70% |
| 安装调试 | 设备安装调试 | 10-15% |
| 基础设施 | 地面加固/电力改造 | 5-10% |

| 培训 | 操作培训 | 2-3% |
| 预备费 | 不可预见费 | 5% |

### 2.2 运营成本(OPEX)
| 成本项 | 说明 | 典型占比 |
|--------|------|---------|
| 电耗 | 设备运行电费 | 40-50% |
| 维护保养 | 定期维护 | 25-35% |
| 备品备件 | 更换配件 | 15-20% |
| 人工 | 增加的操作人员 | 5-10% |
| 软件维护 | 系统升级维护 | 3-5% |

## 三、收益计算

### 3.1 收益来源
| 收益类型 | 计算方式 | 说明 |
|---------|---------|------|
| 人工成本节约 | 减少人数×年工资 | 主要收益 |
| 空间节约 | 减少面积×租金 | 高层货架 |
| 效率提升 | 产出增加/单位降低 | 效率溢价 |
| 准确率提升 | 减少损失 | 减少赔款 |
| 破损率降低 | 减少货损 | |
| 速度提升 | 响应加快 | 竞争优势 |

### 3.2 人工节约计算
```
年人工节约 = 减少人数 × (年均工资 + 年均社保公积金 + 年均补贴)
```

### 3.3 空间节约计算
```
年空间节约 = 减少面积 × 月租金 × 12
```

### 3.4 效率提升收益
```
年效率收益 = 单位时间产出增加 × 时间价值
```

## 五、完整计算示例

### 示例：AGV搬运系统

**项目参数**：
```
- AGV投资：200万元
- 安装调试：30万元
- 基础设施：10万元
- 软件系统：20万元
- 项目管理：10万元
- 预备费：15万元
- 总投资：285万元

- 原有叉车/人工配置：10人
- 自动化后配置：3人
- 减少人数：7人
- 年人均成本：12万元/人
- 年运营维护成本：25万元
- 设备寿命：10年
```

**计算**：
```
1. 年人工节约 = 7 × 12 = 84万元

2. 年净收益 = 84 - 25 = 59万元

3. 投资回收期 = 285 / 59 = 4.83年

4. 10年总收益 = 59 × 10 = 590万元

5. 10年净收益 = 590 - 285 = 305万元

6. ROI = (59 / 285) × 100% = 20.7%

7. 5年ROI = (59 × 5 - 285) / 285 × 100% = 3.5%
  (5年刚好回本)
```

### 示例：自动分拣系统

**项目参数**：
```
- 分拣设备投资：400万元
- 安装调试：60万元
- 基础设施：40万元
- 软件系统：50万元
- 项目管理：30万元
- 预备费：30万元
- 总投资：610万元

- 原分拣人员：20人
- 自动化后：4人
- 减少人数：16人
- 年人均成本：10万元/人
- 破损率降低收益：10万元/年
- 效率提升收益：30万元/年
- 年运营维护成本：55万元
- 设备寿命：12年
```

**计算**：
```
1. 年人工节约 = 16 × 10 = 160万元
2. 年其他收益 = 10 + 30 = 40万元
3. 年总收益 = 160 + 40 = 200万元
4. 年净收益 = 200 - 55 = 145万元
5. 投资回收期 = 610 / 145 = 4.21年
6. 12年总净收益 = 145 × 12 - 610 = 1130万元
7. ROI = (145 / 610) × 100% = 23.8%
```

## 七、风险调整

### 7.1 风险系数
| 风险类型 | 调整方式 | 建议系数 |
|---------|---------|---------|
| 技术风险 | 降低收益预期 | 0.8-0.9 |
| 需求波动 | 降低利用率假设 | 0.7-0.8 |
| 成本超支 | 增加投资 | 1.1-1.2 |
| 运营风险 | 降低效率提升 | 0.7-0.9 |

### 7.2 敏感性分析
| 变量变化 | 对回收期影响 |
|---------|------------|
| 投资+10% | 回收期+10% |
| 投资-10% | 回收期-10% |
| 年节约+10% | 回收期-9% |
| 年节约-10% | 回收期+11% |
| 运营成本+10% | 回收期+8% |

## 八、决策标准

### 8.1 投资决策指标
| 指标 | 最低标准 | 良好标准 | 优秀标准 |
|------|---------|---------|---------|

| ROI | ≥15% | ≥20% | ≥25% |
| NPV | >0 | >投资额30% | >投资额50% |

- 柔性扩展能力

- 运维响应能力
- 员工接受度
