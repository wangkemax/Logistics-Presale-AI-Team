# 运输成本模型

> 服务于 Cost Model Agent，用于自动测算运输配送成本

## 一、运输成本结构

### 1.1 运输成本组成
| 成本项 | 说明 | 占比参考 |
|--------|------|---------|
| 车辆成本 | 车辆折旧/租赁 | 25-35% |
| 燃油费 | 油料消耗 | 25-35% |
| 人工费 | 司机工资 | 20-30% |
| 路桥费 | 高速通行费 | 5-15% |
| 维修保养 | 车辆维护 | 5-10% |
| 保险 | 交强险/商业险 | 3-5% |
| 其他 | 停车/违章等 | 2-5% |

## 三、核心计算模型

### 3.1 单次运输成本
```
单次运输成本 = 车辆成本 + 燃油费 + 人工成本 + 路桥费 + 维修费 + 保险
```

**分项计算**：
```
车辆折旧成本 = 车辆价格 / 折旧年限 / 年运输趟数
```

**燃油费**：
```
燃油费 = (D / 100) × R_fuel × P_fuel × 2  (往返)
```

**人工成本分摊**：
```
人工成本 = 司机月成本 × (D×2 / 日均行驶里程) / 月工作天数
```

**路桥费**：
```
路桥费 = D × 2 × R_toll × 趟数
```

### 3.2 吨公里成本
```
吨公里成本 = 单次总成本 / (D × 2 × 载重)
```

### 3.3 单位配送成本
```
单位配送成本 = 月度总成本 / 月配送票数
```

## 四、运输模式计算

### 4.1 城市配送（短途）
**适用场景**：同城配送，最后一公里

```
参数示例：
- 配送距离：30km（单程）
- 载重：2吨
- 车辆：4.2m厢式货车
- 月配送趟数：100趟

计算：
- 月行驶里程 = 30 × 2 × 100 = 6,000km
- 燃油费 = 60 × 2.5 × 100 = 15,000元
- 路桥费 = 30 × 2 × 0.3 × 100 = 1,800元
- 车辆折旧 = 200,000 / 60 / 100 = 3,333元/月
- 司机成本 = 8,000 / 22 / 100 × 60 = 218元/趟
- 单趟成本 = 3333 + 15000/100 + 1800 + 218 = 7,551元
- 单位成本 = 7551 / 2 / 30 = 126元/吨
```

### 4.2 干线运输（长途）
**适用场景**：城市间运输

```
参数示例：
- 运输距离：500km（单程）
- 载重：20吨
- 车辆：17.5m厢式货车
- 月运输趟数：10趟

计算：
- 月行驶里程 = 500 × 2 × 10 = 10,000km
- 燃油费 = 100 × 28 / 100 × 7.5 × 10 = 21,000元
- 路桥费 = 500 × 2 × 0.5 × 10 = 5,000元
- 车辆折旧 = 800,000 / 72 / 10 = 1,111元/月
- 司机成本 = 10,000 × 2 / 10 = 2,000元/趟
- 单趟成本 = 1111 + 21000/10 + 5000 + 2000 = 11,111元
- 单位成本 = 11111 / 20 / 500 = 1.11元/吨公里
```

## 五、影响因素与系数

### 5.1 距离系数
| 距离区间 | 系数 | 说明 |
|---------|------|------|
| 0-50km | 1.5-2.0x | 城市配送，成本高 |
