# 仓储租金成本模型

> 服务于 Cost Model Agent，用于自动测算仓储项目租金成本

---

## 一、成本结构

### 1.1 仓储租金组成
| 成本项 | 说明 | 占比参考 |
|--------|------|---------|
| 仓库租金 | 核心成本 | 60-70% |
| 物业管理费 | 公共区域服务 | 10-15% |
| 水电费 | 照明+设备 | 10-20% |
| 维护费 | 日常维护 | 3-5% |
| 保险费 | 财产保险 | 2-3% |
| 其他费用 | 垃圾处理等 | 1-2% |

---

## 二、变量定义

| 变量 | 符号 | 说明 | 单位 | 典型取值 |
|------|------|------|------|---------|
| 仓库面积 | A | 租赁面积 | m² | 依需求 |
| 单价 | P | 元/m²/月 | 元/m²/月 | 20-80 |
| 物业管理费率 | R_pm | 占租金比例 | % | 10-20% |
| 单位水电费 | C_util | 每月水电 | 元/m² | 2-8 |
| 保险费率 | R_ins | 占租金比例 | % | 0.5-1% |
| 空置期 | T_vac | 装修免租期 | 月 | 1-3 |

---

## 三、核心计算模型

### 3.1 月度仓储成本
```
月度仓储成本 = 仓库月租 + 物业管理费 + 水电费 + 维护费 + 保险费
```

### 3.2 分项计算

**仓库月租**：
```
月租金 = A × P
```

**物业管理费**：
```
月物业费 = A × P × R_pm
```

**水电费**：
```
月水电费 = A × C_util
```
> 或按实际计量计算

**维护费**：
```
月维护费 = A × 维护单价的估算
```

**保险费**：
```
月保险费 = 库存价值 × R_ins / 12
```

### 3.3 冷库/恒温库附加
```
冷库成本 = 常温成本 × (1.5 - 3.0)
```
**影响因素**：温控要求、能耗效率、地区差异

---

## 四、单位成本计算

### 4.1 单位仓储成本
```
单位仓储成本 = 月度仓储总成本 / 月均订单量
```

### 4.2 面积利用率调整
```
有效成本 = 月度成本 / 实际利用率
```
> 实际利用率通常为60-80%

### 4.3 库存周转调整
```
吨/立方米日均成本 = 月度仓储成本 / (月均库存量 × 30)
```

## 五、完整计算示例

### 示例：常温平面仓
```
基础参数：
- 租赁面积：3000 m²
- 租金单价：35 元/m²/月
- 物业费率：15%
- 水电费：5 元/m²/月
- 维护费：2 元/m²/月
- 保险费率：0.5%
- 库存价值：1000万元

计算：
1. 月租金 = 3000 × 35 = 105,000元
2. 月物业费 = 105,000 × 15% = 15,750元
3. 月水电费 = 3000 × 5 = 15,000元
4. 月维护费 = 3000 × 2 = 6,000元
5. 月保险费 = 10,000,000 × 0.5% / 12 = 4,167元
6. 月度仓储总成本 = 105,000 + 15,750 + 15,000 + 6,000 + 4,167 = 145,917元
7. 单位面积成本 = 145,917 / 3000 = 48.64 元/m²/月
```

### 示例：冷链仓储
```
基础参数（在上例基础上）：
- 温控要求：2-8℃
- 冷库系数：2.5x
- 库存价值：500万元

计算：
1. 冷库月租金 = 105,000 × 2.5 = 262,500元
2. 冷库物业费 = 262,500 × 15% = 39,375元
3. 冷库水电费 = 3000 × 5 × 3 = 45,000元（冷库能耗3倍）
4. 月度仓储总成本 = 262,500 + 39,375 + 45,000 + 6,000 + 2,083 = 354,958元
5. 单位面积成本 = 354,958 / 3000 = 118.32 元/m²/月
```

## 六、租金影响因素

### 6.1 地区差异系数
| 地区 | 系数 | 说明 |
|------|------|------|
| 一线城市核心 | 2.0-3.0x | 北京/上海/广州/深圳核心区 |
| 一线城市郊区 | 1.0-1.5x | 城市周边 |
| 二线城市 | 0.6-1.0x | 成都/武汉/杭州等 |
| 三四线城市 | 0.3-0.6x | 地级市 |

### 6.2 仓库类型系数
| 仓库类型 | 系数 | 说明 |
|---------|------|------|
| 普通平面仓 | 1.0x | 基准 |
| 立体仓 | 1.2-1.5x | 带货架 |
| 楼库 | 0.7-0.9x | 多层，效率低 |
| 恒温/冷藏 | 2.0-4.0x | 温控需求 |
| 危险品仓 | 1.5-2.5x | 特殊资质 |

### 6.3 其他影响因素
| 因素 | 影响方向 | 说明 |
|------|---------|------|
| 层高 | 正向 | 层高越高，利用率↑ |
| 地面承重 | 正向 | 承重高→适用广 |
| 月台配置 | 正向 | 有月台→效率↑ |
| 消防等级 | 正向 | 高等级→安全↑ |

## 七、成本优化建议

### 7.1 降低仓储成本的途径
| 措施 | 预期效果 | 实现方式 |
|------|---------|---------|
| 提高面积利用率 | 降低10-20% | 立体存储、合理布局 |
| 选址优化 | 降低15-30% | 郊区化+物流配套 |
| 弹性租赁 | 降低10-15% | 峰值外租+短租 |
| 自动化存储 | 降低20-30%面积 | 提高容积率 |
| 共用仓储 | 降低10-20% | 多客户共享 |

### 7.2 租赁合同优化
| 条款 | 建议 |
|------|------|
| 租期 | 3-5年，附续约权 |
| 递增 | CPI或固定3-5% |
| 免租期 | 争取1-3个月 |
| 扩租权 | 保留扩租选择 |
| 退出条款 | 提前6个月通知 |
