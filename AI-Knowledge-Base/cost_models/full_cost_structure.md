## 三、核心计算模型

### 3.1 月度总成本
```
月度总成本 = 人工成本 + 仓储成本 + 运输成本 + 耗材成本 + 设备成本 + 管理成本
```

### 3.2 分项成本计算

**人工成本**：
```
月人工成本 = (日均订单/ 人效) × (月均工资 × (1+社保比率)) × 月均加班系数
```

**仓储成本**：
```
月仓储成本 = 面积 × (租金单价 + 租金单价 × 物业比率 + 水电单价) × 利用率调整
```

**运输成本**：
```
月运输成本 = 日均订单 × 月天数 × 平均订单重量/1000 × 运输单价
```

**耗材成本**：
```
月耗材成本 = 日均订单 × 月天数 × 耗材单价
```

**设备成本**：
```
月设备成本 = 设备月折旧 + 设备月租赁
```

**管理成本**：
```
月管理成本 = 固定管理费 + 人工成本 × 管理费率
```

## 四、完整计算示例

### 示例：电商B2C仓储项目

```
基础参数：
- 日均订单：2000单
- 月工作天数：21.75天
- 人效指标：120单/人/天
- 月均工资：5500元
- 社保比率：32%
- 仓库面积：3000m²
- 租金单价：35元/m²/月
- 物业比率：15%
- 水电单价：5元/m²/月
- 平均运距：30km
- 运输单价：0.8元/吨公里
- 平均单重：2kg
- 耗材单价：3.5元/单
- 设备月折旧：3万元
- 管理费率：5%
```

**计算**：

```
1. 月订单量 = 2000 × 21.75 = 43,500单

2. 人工成本：
   - 配置人数 = 2000 / 120 = 16.67 ≈ 17人
   - 月人均成本 = 5500 × 1.32 = 7,260元
   - 月人工成本 = 17 × 7260 × 1.1(加班) = 135,882元

3. 仓储成本：
   - 月仓储成本 = 3000 × (35 + 35×0.15 + 5) = 3000 × 45.25 = 135,750元

4. 运输成本：
   - 月运输成本 = 43500 × 0.002吨 × 30km × 0.8 = 20,880元

5. 耗材成本：
   - 月耗材成本 = 43500 × 3.5 = 152,250元

6. 设备成本：
   - 月设备成本 = 30,000元

7. 管理成本：
   - 月管理成本 = 135,882 × 5% = 6,794元

8. 月度总成本 = 135,882 + 135,750 + 20,880 + 152,250 + 30,000 + 6,794 = 481,556元

9. 单位成本 = 481,556 / 43,500 = 11.07元/单
```

## 六、盈亏平衡分析

### 6.1 盈亏平衡点计算
```
盈亏平衡订单量 = 固定成本 / (单价 - 单位变动成本)
```

### 6.2 示例续算
```
假设报价：15元/单
固定成本 = 人工基础 + 仓储 + 设备 + 管理 = 135,882 + 135,750 + 30,000 + 6,794 = 308,426元
单位变动成本 = 运输 + 耗材 = 20,880/43,500 + 152,250/43,500 = 0.48 + 3.50 = 3.98元/单

盈亏平衡量 = 308,426 / (15 - 3.98) = 27,958单/月
盈亏平衡利用率 = 27,958 / 43,500 = 64.3%
```
