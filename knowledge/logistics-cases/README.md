# 物流案例库

> 存放历史物流/仓储/供应链项目案例，按行业或项目类型分类。

## 目录结构

```
logistics-cases/
├── README.md           # 本文件
├── <行业>/
│   ├── README.md       # 该行业案例索引
│   ├── <项目名>.md      # 单个案例文档
│   └── assets/         # 附件（平面图/流程图/数据表）
```

## 案例文档标准模板

```yaml
# 项目名称
- 客户名称（脱敏处理）: xxx
- 行业: xxx
- 项目规模: 
  - 仓库面积: xxx m²
  - 日均订单量: xxx 票/天
  - 峰值订单量: xxx 票/天
  - SKU 数量: xxx
- 服务内容: xxx
- 合同金额/报价区间: xxx
- 项目周期: xxx
- 核心技术亮点:
  - xxx
- KPI 达成情况:
  - xxx
- 可复用经验:
  - xxx
- 风险提示:
  - xxx
```

## 分类建议

- `ecommerce/` — 电商仓配案例
- `cold-chain/` — 冷链物流案例
- `manufacturing/` — 制造业供应链案例
- `retail/` — 零售配送案例
- `cross-border/` — 跨境物流案例
