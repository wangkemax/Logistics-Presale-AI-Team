- **核心+弹性**：40%旺季增量使用储备临工，60%为提前招募并培训合格的人员
- **跨仓调配**：大DC之间建立人员互调机制，旺季高峰支持中小DC
- **奖金激励**：设置旺季作业奖金，留住熟练工人

## 3.4 作业流程设计

### 3.4.1 入库流程

```
Step 1：车辆到达预约
  → 车辆抵达前通过TRTVS系统预约卸货时间
  → 门卫登记，核查司机信息与订单匹配
  → 引导至指定月台停车位

Step 2：卸货与初检
  → 卸货前检查车厢温度（食品合规：温度异常拒收）
  → 外观检查：包装破损、污染、异物
  → 核对ASN（预先发送的到货通知单）与实物数量/批次

Step 3：码托与贴标
  → 按1M×1.2M标准托盘码托，层高≤1.8m
  → 每托贴箱数标签（含：品名、数量、批次号、效期）
  → 异常品（破损/温控异常）单独隔离，不入库

Step 4：WMS入库登记
  → 扫描托盘标签，录入WMS：品名、批次、效期、库位
  → WMS自动分配最优库位（A/B/C区）
  → 打印库位标签，贴于托盘侧面

Step 5：叉车送仓
  → 叉车司机接收任务，按库位标签送至指定货架
  → 库位扫描确认，完成WMS库位绑定

Step 6：入库确认与单据
  → WMS生成入库单，SAP自动同步
  → 单据归档：ASN + 入库单 + 质检报告
```

### 3.4.2 在库流程

| 日常管理 | 盘点管理 | 移库/整理 |
|---------|---------|---------|
| 温湿度监控：每日记录2次 | A类（高频品）：每日动盘≥20%SKU | 库位优化：WMS自动计算最优库位 |
| 效期管理：WMS预警，效期≤60天提前复盘 | B类（中频品）：每周盘点≥30%SKU | 翻箱管理：效期相近产品合并，减少损耗 |
| 库龄分析：超期品触发处理流程 | C类（低频品）：月度全盘 | 报废处理：按合同流程，合规报废 |
| — | 月度全盘：每月最后一个工作日 | — |

### 3.4.3 出库流程

```
Step 1：订单接收与确认
  → 接收百事SAP订单，WMS自动解析
  → 订单审核：库存可用性、发货优先级

Step 2：波次优化
  → WMS按路线/客户/车型进行波次分组
  → 整托订单优先处理（减少拆托）
  → 零散订单合并拣货，提升效率

Step 3：拣货任务执行
  → 整托：叉车直接按库位取货，扫描确认
  → 拆零：RF扫描拣货，按单逐箱操作
  → 整托PDQ：优先处理，配送费×1.8倍

Step 4：暂存区合单
  → 按发货路线/客户分组码放
  → 装车清单打印，作业员对照清点

Step 5：装车复核
  → 逐箱扫描出库，确认品项与数量
  → 异常件（错发/多发）立即拦截，不上车
  → 装车后：托盘拍照+POD准备

Step 6：发车与跟踪
  → TRTVS记录发车时间、路线
  → GPS实时跟踪，异常即时报警
  → 客户签收：POD拍照上传TRTVS
```

### 3.4.4 逆向物流流程

```
退货接收 → 退货质检（品名/数量/破损/效期）
         ↓
    ┌─ 可售品 → 复检合格后返库（更新WMS库位）
    ↓
分级处理
    ├─ 残次品 → 协商折价处理或报废
    └─ 过期品 → 直接进入报废流程
         ↓
报废处理 → 集中暂存报废暂存区 → WMS更新 → 与有资质废品处理公司当日清运

运费规则：退货拉回DC，百事不承担运费（不可抗因素除外）
```

### 3.4.5 配送落档计价规则

按合同要求，配送按箱数落档计价，共分6个坎级：

| 坎级（箱） | 单价系数 | 说明 |
|-----------|---------|------|
| ≥1,500 | 1.0x（基础价） | 投标方仅需报此档价格 |
| 1,000≤X<1,500 | 1.15x | 坎级下降一级×1.15 |
| 500≤X<1,000 | 1.32x | （1.15²） |
| 150≤X<500 | 1.52x | （1.15³） |
| 20≤X<150 | 1.75x | （1.15⁴） |
| <20 | 2.01x | （1.15⁵） |

**整托PDQ产品配送费** = 正常运费 × 1.8倍（合同明确约定）
