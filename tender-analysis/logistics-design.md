### 1.3 关键区域详细规划

#### 月台设计
- **卸货月台**：外置月台优先，配置防雨棚；月台高度1.2m（适配标准货车）；月台门数量按日均卸货能力配置（大DC 12-16个，中DC 8-12个，小DC 4-8个）
- **装车月台**：与卸货月台物理分离，避免交叉；装车口配置升降平台
- **月台管理**：安装车辆预约系统（TRTVS对接），控制月台进出；月台通道宽度≥8m，保证多车同时作业

#### 货架存储区
- **货架类型**：横梁式货架（重型）+窄通道货架（VNA）+地堆区
- **板位计算**：板位数 = 面积 × 0.92 × 0.83（参照百事标准）
- **铲板规格**：统一 1M × 1.2M（木质/塑料标准托盘）
- **存储分区**：ABC分类管理
  - A类（高周转）：靠近月台，货架优先层，缩短搬运动线
  - B类（中周转）：中部货架层
  - C类（低周转/季节性）：高层货架或地堆

#### 退货处理区
- 独立隔离区域，面积约为存储区的3-5%
- 配备专用退货通道（避免与正品交叉）
- 退货质检台 + 报废暂存区（需与有资质废品处理公司签约）

#### 叉车充电/维护区
- 独立建筑分区，与产品存储区物理隔离
- 配置消防喷淋 + CO₂灭火器
- 充电桩比例：每3台电动叉车配置1个充电桩 + 1组备用电池

### 1.4 作业动线设计

#### 入库动线（单流向，无折返）
```
车辆到达 → 月台停靠 → 卸货初检（温度/外观）→ 码托/组托 
→ 托盘贴标（品名/批次/效期）→ 叉车送仓 → WMS确认上架 → 库位绑定
```

#### 出库动线
```
订单接收 → WMS波次优化 → 拣货任务生成 → RF扫描拣货 → 暂存区合单 
→ 装车复核 → 装车扫描确认 → WMS出库确认 → TRTVS发货跟踪 → POD签收
```

#### 交叉防范动线
- 入库月台（北侧）与出库月台（南侧）物理分离
- 退货通道独立，不穿越正品存储区
- 报废品从报废暂存区直接由专用出口运出，不经过装车月台

### 1.5 CNY旺季布局应对
- **前置仓启用**：11月起启动临仓（提前2个月筹备），临仓面积≈本仓面积/12×12×1.3
- **旺季分区**：旺季货物专区管理，本仓与临仓通过WMS库存透明管理
- **临仓启用时间**：11月~2月（约60天），阶梯式增加，每10-15天为一周期

#### 1.5.1 CNY临时仓选址标准

**选址基本原则（按SOW 2.5节要求）**

第三方有责任在旺季找到合适的地理位置、合理价格的临时仓库。选址须满足以下标准：

| 评估维度 | 具体要求 | 权重 |
|---------|---------|------|
| 距离主仓 | ≤15km车程（紧急调货2小时内到达） | 25% |
| 仓库资质 | 丙2类仓库，配备喷淋，有消防验收证 | 20% |
| 仓库条件 | 地面不起灰（合同4.1节），排水完善，无漏水隐患 | 15% |
| 净面积 | 满足临仓面积计算需求（见1.5.2） | 15% |
| 租赁价格 | ≤主仓同类区域均价的120%（淡季参考） | 15% |
| 合作历史 | 优先已有合作关系的物流园/仓库 | 10% |

**实地勘察 Checklist（签约前必查）**

- [ ] 仓库产权证+消防验收证原件
- [ ] 喷淋系统测试记录（最近一次测试时间）
- [ ] 地面承重证明（≥1.5吨/㎡）
- [ ] 周边道路限高/限行情况（货车能否直达）
- [ ] 仓库净高（≥5m，确保货架叉车作业空间）
- [ ] 仓库照明条件（自然采光+人工照明）
- [ ] 排水系统测试（模拟暴雨条件）
- [ ] 周边安全隐患（易燃物堆放、工业废气等）

> **临仓面积计算公式**：临仓预估面积 = 主仓面积 ÷ 12 × 旺季倍数 × 安全系数

> 小DC（面积≤6,000㎡）：临仓面积 ≈ 主仓面积 × 0.13（约1/8主仓面积）
> 注：临仓按净面积的65%有效使用率折算（扣除通道/设备/办公区）

#### 1.5.4 临时仓与主仓协调流程

```
【Step 1】选址与签约（T-120天至T-90天）
  → DC总监牵头，运营团队实地勘察≥3个候选仓库
  → 法务审核仓库资质（产权证/消防证/喷淋系统）
  → 商务谈判：租赁价格≤同类仓库均价120%，租期覆盖旺季（12月-3月，共4个月）
  → 签约：与业主签订临时仓储合同（含百事资质要求条款）

【Step 2】临仓改造与系统配置（T-90天至T-30天）
  → 临仓基础改造：地面清洁/照明修复/消防检查
  → WMS系统延伸：临仓库位编码规则与主仓一致，前缀区分（如"FSDC-L1"）
  → IT网络接通：临仓WIFI覆盖，接入主仓SAP/WMS系统
  → 设备预置：叉车/托盘/货架/办公设备入场

【Step 3】临仓启用（橙色预警触发）
  → 货物转移原则：先进先出，低周转SKU优先转移至临仓
  → 转移计划：每日转移量≤主仓日均入库量的50%，避免转移过程造成库存混乱
  → 库位映射：WMS系统完成临仓与主仓的库存关联，支持跨仓调拨
  → 人员就位：临仓管理员+叉车司机+拣货员到位，完成培训

【Step 4】旺季运营（高峰期间）
  → 库存透明：WMS实时显示主仓+临仓合计库容，本仓利用率≥95%时自动预警
  → 订单分流：整托订单优先主仓；高周转SKU保留主仓；低周转/大体积SKU导流临仓
  → 调拨响应：主仓与临仓之间调拨响应时间≤4小时（临仓距主仓≤15km）
  → 质量管控：临仓执行与主仓同等温湿度监控和效期管理标准

【Step 5】临仓关闭与库存回流（旺季结束后）
  → 回流时机：主仓库存利用率降至75%以下，且距春节≥30天
  → 回流顺序：临仓低周转SKU→主仓；临仓高周转SKU→主仓优先位置（FIFO）
  → 关闭检查：临仓清空后，与主仓WMS库存对账（准确率需达99.9%）
  → 结算归档：与临仓业主结算；临工遣散；临仓运营数据归档复盘
```

## 2. 人员配置方案

### 2.1 组织架构（每DC直营模式）

```
DC总监（1人）
  ├── 仓库经理（1人）
  │     ├── 入库主管（1人）
  │     │     ├── 入库组长（按班组配置）
  │     │     └── 入库作业员（4-8人，按DC规模）
  │     ├── 在库主管（1人）
  │     │     ├── 叉车司机（4-10人）
  │     │     ├── 拣货员（4-12人）
  │     │     └── 盘点员（1-3人）
  │     ├── 出库主管（1人）
  │     │     ├── 出库组长（按班组配置）
  │     │     └── 出库作业员（4-8人）
  │     └── 退货/报废处理员（2-4人）
  ├── 配送主管（1人，仅大DC独立设置；中小DC由仓库经理兼任）
  │     └── 配送专员/调度（1-2人）
  ├── 质检主管/QC（1人）
  │     └── 质检员（2-4人）
  ├── 设备维护（1-2人）
  └── 行政/单证（1-2人）
```

## 4. 作业流程设计

### 4.1 入库流程

```
【Step 1】车辆到达与预约
  → 车辆抵达DC前通过TRTVS系统预约卸货时间
  → 门卫登记，核查司机信息与订单匹配
  → 引导至指定月台停车位

【Step 2】卸货与初检
  → 卸货前检查车厢温度（食品合规：温度异常拒收）
  → 外观检查：包装破损、污染、异杂物
  → 核对ASN（预先发送的到货通知单）与实物数量/批次

【Step 3】码托与贴标
  → 按1M×1.2M标准托盘码托，层高≤1.8m
  → 每托贴箱数标签（含：品名、数量、批次号、效期）
  → 异常品（破损/温控异常）单独隔离，不入库

【Step 4】WMS入库登记
  → 扫描托盘标签，录入WMS：品名、批次、效期、库位
  → WMS自动分配最优库位（A/B/C区）
  → 打印库位标签，贴于托盘侧面

【Step 5】叉车送仓
  → 叉车司机接收任务，按库位标签送至指定货架
  → 库位扫描确认，完成WMS库位绑定
  → 异常库位（满/错）即时反馈，重新分配

【Step 6】入库确认与单据
  → WMS生成入库单，SAP自动同步
  → 单据归档： ASN+入库单+质检报告
```

---

### 4.2 在库流程

```
【日常管理】
  → 温湿度监控：每日记录2次（冷食/常温分区监控）
  → 效期管理：WMS预警，效期≤60天提前复盘
  → 库龄分析：超期品触发处理流程

【盘点管理（合同KPI：库存准确率99.9%）】
  → A类（高频品）：每日动盘，比例≥20%
  → B类（中频品）：每周盘点，覆盖≥30%
  → C类（低频品）：月度全盘
  → 月度全盘：每月最后一个工作日全量盘点

【移库/整理】
  → 库位优化：WMS自动计算最优库位，执行移库
  → 翻箱管理：效期相近产品合并，减少损耗
  → 报废处理：按合同流程，执行合规报废
```

---

### 4.3 出库流程

```
【Step 1】订单接收与确认
  → 接收百事SAP订单，经WMS自动解析
  → 订单审核：库存可用性、发货优先级
  → 节假日/旺季：提前与客户确认订单截止时间

【Step 2】波次优化
  → WMS按路线/客户/车型进行波次分组
  → 整托订单优先处理（减少拆托）
  → 零散订单合并拣货，提升效率

【Step 3】拣货任务执行
  → 整托：叉车直接按库位取货，扫描确认
  → 拆零：RF扫描拣货，按单逐箱操作
  → 整托PDQ：优先处理，配送费×1.8倍（合同4.3节）

【Step 4】暂存区合单
  → 按发货路线/客户分组码放
  → 装车清单打印，作业员对照清点

【Step 5】装车复核
  → 逐箱扫描出库，确认品项与数量
  → 异常件（错发/多发）立即拦截，不上车
  → 装车后：托盘拍照+POD准备

【Step 6】发车与跟踪
  → TRTVS记录发车时间、路线
  → GPS实时跟踪，异常即时报警
  → 客户签收：POD拍照上传TRTVS
```

---

### 4.4 逆向物流流程

```
【退货接收】
  → 客户提交退货申请（系统/RF）
  → 退货预约：WMS退货队列管理
  → 退货到达：与正品分离通道，卸货至退货处理区

【质检与分类】
  → QC质检：品名、数量、破损程度、效期
  → 分级处理：
    ├ 可售品 → 复检合格后返库（更新WMS库位）
    ├ 残次品 → 协商折价处理或报废
    └ 过期品 → 直接进入报废流程

【报废处理】
  → 集中暂存于报废暂存区（与废品处理公司当日清运）
  → WMS更新：减少库存，生成报废单
  → 报废执行：与有资质废品处理公司签约（合同M14）
  → 三码合一产品：特定流程处理（合同要求）

【运费规则】
  → 退货拉回DC：DC不承担运费（合同2.2节，不可抗因素除外）
  → 报废品处置：含在报废费报价中（合同约定）
```

---

### 4.5 CNY旺季特殊流程

> **详细执行方案见第一章1.5节**，以下为流程摘要

- **临时仓启用**：11月启动临仓，提前完成WMS系统配置（临仓库位映射）；启用触发条件、选址标准、协调流程详见1.5.1-1.5.4
- **订单分流**：大订单优先本仓，高峰期订单导流至临仓；低周转SKU导流临仓，高周转SKU保留主仓（详见1.5.4 Step 4）
- **人员激活**：旺季前2周完成所有储备人员的培训和上岗认证；临仓人员配置方案详见1.5.5
- **数据隔离**：旺季临仓库存与本仓在WMS中分区管理，避免混淆；临仓库位编码前缀区分（如"FSDC-L1"）

## 6. 安全与合规

### 6.1 安全规范

#### 消防安全（丙2类仓库强制要求）
- **喷淋系统**：全仓库配置自动喷淋头（覆盖所有存储区+月台+叉车充电区）
- **消防栓**：每50㎡配置1个消防栓，月台区加密
- **灭火器**：CO₂灭火器（电器区）+干粉灭火器（货品区），每10m配置1组
- **消防通道**：主通道宽度≥3.5m，保持畅通，禁止堆货
- **消防演习**：每季度1次全员消防演练
- **电气安全**：叉车充电区与存储区物理隔离，充电桩有专项电路保护

#### 叉车安全（合同M9强制）
- **必须为电动叉车**（合同强制，不可使用燃油叉车）
- **持证上岗**：叉车司机必须持叉车操作证，在岗期间随身携带
- **点检制度**：每班前15分钟叉车点检，记录存档
- **限速行驶**：仓库内最高时速5km/h，弯道/交叉路口鸣笛
- **载重限制**：严禁超载，提货高度≤4m（货架内）
- **充电安全**：充电区禁烟火，充电时开启通风

#### 人员安全
- **安全培训**：入职培训+季度复训，记录存档
- **PPE配置**：安全帽、反光背心、安全鞋（仓库内强制穿戴）
- **门禁管理**：仓库入口门禁，访客登记+陪同制度
- **应急通道**：紧急出口标识清晰，每月检查畅通

---

### 6.2 质量控制

#### 食品安全（食品仓储合规）
- **温控合规**：
  - 常温食品：库内温度5-30℃，每日记录2次
  - 温敏食品（如有）：按品类要求严格管控
  - 温控异常品：立即隔离，不合格品不上架
- **效期管理**：
  - WMS自动预警：效期≤90天触发预警
  - 先进先出（FIFO）：库位设计+拣货规则强制执行
  - 过期品：立即进入报废流程，不对外发货
- **卫生管理**：
  - 每日仓库清洁（地面+货架+月台）
  - 每周仓库消毒（食品级消毒剂）
  - 专业除虫公司合作（合同M15强制要求）+ 合同存档

#### 货品防护
- **防盗防损**：仓库全区域监控覆盖，门禁+摄像头无死角
